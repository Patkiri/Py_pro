วิธีใช้
1.) ตั้งค่า OneDrive ให้ซิงก์ไฟล์วิชาลงเครื่อง (ใน Teams แท็บ Shared กด Add shortcut to OneDrive แล้วคลิกขวาที่โฟลเดอร์เลือก Always keep on this device)
2.) แก้ SOURCE_DIR = "" ให้ชี้ไปโฟลเดอร์แม่ 
3.) รัน py -m pip install playwright
4.) ครั้งแรก จะมีหน้าต่าง Chrome ใหม่เปิดขึ้น ให้ล็อกอิน Google ในหน้าต่างนั้น (สคริปต์รอให้เอง ไม่ต้องกด Enter) ครั้งต่อไปจะจำการล็อกอินไว้
5.) ระหว่างสคริปต์ทำงาน อย่าปิดหน้าต่าง Chrome จนกว่าจะขึ้นว่า "เสร็จแล้ว"
6.) เมื่ออาจารย์แชร์ไฟล์ใหม่และ OneDrive ซิงก์ลงเครื่อง ให้รันสคริปต์อีกครั้ง จะอัปโหลดเฉพาะไฟล์ใหม่
